# My Days — личный дневник

Русскоязычное офлайн PWA для ежедневных записей. Статическое приложение на HTML, CSS и JavaScript: без регистрации, облачной базы, аналитики и внешних API.

## Публикация

Проект публикуется GitHub Pages из корня ветки `main`. Все пути относительные и работают в подпапке `/my-days/`.

## Функции

- обязательный пароль при каждом запуске;
- шифрование дневника на устройстве через Web Crypto (PBKDF2-HMAC-SHA-256 и AES-GCM-256);
- автоматическое сохранение заметок, настроения, привычек, трекеров и ежемесячных напоминаний;
- ручная блокировка и блокировка после двух минут в фоне;
- календарь и статистика за неделю, месяц и год;
- зашифрованный ZIP-экспорт и восстановление на другом устройстве;
- импорт старых JSON/ZIP резервных копий (аудиодорожки в старых архивах игнорируются);
- адаптивный интерфейс и офлайн-кэш приложения.

## Пароль и данные

Регистрация не нужна. При первом запуске пользователь задаёт пароль длиной от 12 символов. Из пароля с уникальной случайной солью получается ключ AES-GCM-256 через PBKDF2-HMAC-SHA-256 с 600 000 итераций. Дневниковые записи и настройки сохраняются в IndexedDB в зашифрованном виде; ключ остаётся в памяти только пока приложение разблокировано.

Пароль не отправляется на GitHub или другой сервер. GitHub Pages отдаёт только файлы приложения. Сайт шифрует данные локально; это не защищает от вредоносного кода, внедрённого в сам origin, или от человека, который пользуется уже разблокированным устройством. Используй пароль устройства и блокируй My Days, когда отходишь.

Пароль нельзя сбросить и нельзя восстановить из GitHub. Если его забыть, записи и ZIP-копии, защищённые этим же паролем, открыть нельзя. При смене пароля сделай новую резервную копию: старые архивы остаются защищены старым паролем.

Первая установка пароля безопасно переносит существующие текстовые записи в зашифрованное хранилище, очищает старое незашифрованное хранилище и удаляет аудиозаписи. Голосовая запись и импорт аудио удалены из интерфейса и программы. Старые резервные копии без пароля всё ещё могут содержать аудиофайлы — новые импорты их пропускают.

## Резервные копии

Записи сохраняются автоматически; ZIP-копия создаётся вручную по желанию. Новый ZIP содержит зашифрованные записи и открывается паролем, заданным при создании архива. Для переноса задай пароль на новом устройстве и импортируй архив, введя старый пароль копии. Сохраняй ZIP и пароль в безопасном месте. Старые форматы JSON/ZIP поддерживаются для импорта, но импортируемые записи сразу шифруются текущим паролем.
