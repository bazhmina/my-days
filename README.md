# My Days — личный дневник

Русскоязычное офлайн PWA для ежедневных записей. Статическое приложение на HTML, CSS и JavaScript: без сборки, платных сервисов, регистрации, облачных хранилищ и внешних API.

## GitHub Pages

1. Откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку **main** и каталог **/ (root)**, нажмите **Save**.
4. После публикации откройте HTTPS-адрес Pages. Для микрофона, Service Worker и установки PWA нужен HTTPS.

Проект готов к публикации прямо из корня репозитория. Сборка и зависимости не нужны.

## Что есть в приложении

- ежедневная запись, выбор одного из шести настроений, автосохранение;
- отдельные переключатели «Не было / Было» для алкоголя и «Не курила / Курила» для курения, количество и комментарий;
- ежедневные отметки фиксированного списка привычек;
- ежемесячные напоминания с отметкой выполнения и отображением в календаре;
- голосовая запись через микрофон, импорт, воспроизведение, время создания и удаление аудио;
- календарь с эмодзи настроения и переходом к дневнику любого прошедшего дня;
- статистика за неделю, месяц и год, включая распределение настроения, статусы и привычки;
- переносимый ZIP-экспорт с `diary.json`, `manifest.json` и отдельными аудиофайлами, восстановление ZIP и старого JSON-формата;
- адаптивный интерфейс, PWA manifest и кэш приложения для офлайн работы.

## Приватность и резервные копии

Записи, напоминания и аудио сохраняются автоматически в IndexedDB текущего браузера на текущем устройстве. На GitHub Pages находится только код приложения; у приложения нет сервера для дневниковых данных, аналитики или внешних API. Service Worker кэширует только файлы оболочки приложения.

Запись голоса запрашивает разрешение сайта `bazhmina.github.io` на микрофон только после нажатия кнопки записи. Текущий код записывает звук в локальную базу My Days и не отправляет его на GitHub. Аудио попадёт в ZIP только если пользователь сам скачает архив. Разрешение микрофона можно отозвать в настройках сайта браузера.

Safari и отдельное приложение с экрана «Домой» на iPhone могут хранить данные отдельно. Между устройствами/браузерами автоматической синхронизации нет.

Резервная копия создаётся вручную по желанию, например перед переносом или как дополнительная страховка; её не нужно скачивать после каждой записи. Каждый экспорт скачивает отдельный ZIP-файл и не обновляет автоматически предыдущий. Архив — переносимый ZIP-архив со структурой `diary.json`, `manifest.json` и `audio/`. В `diary.json` хранятся записи и ссылки на аудиофайлы; аудиоданные находятся отдельными файлами внутри архива. При восстановлении записи с совпадающими датами заменяются, остальные сохраняются. Старые JSON-копии также можно восстановить. Резервный файл содержит личную информацию — храните его в безопасном месте. Перед очисткой данных сайта создайте копию.

Для установки на iPhone откройте опубликованный адрес в Safari и используйте **Поделиться → На экран Домой**.
